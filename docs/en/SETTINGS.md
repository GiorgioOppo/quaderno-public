## Find a setting

Open **Settings** from the library. Categories are **General**, **Wi-Fi**, **Bluetooth**, **Display**, **Pen and recognition**, **Storage and backup**, **Pen and battery**, **Accounts and services**, **Security**, **Language and keyboard**, **USB-C**, and **About**. Paper Pro also has **SSH access**. **Search settings** filters category names and keywords, not notebook content. Clear the search to restore all categories.

Settings are saved for this installation. They do not travel with a synchronized notebook. If saving fails, the previous preferences remain active and an error is shown. Manual actions remain available alongside the automatic options.

## Rotation, reading and full-page view

Manual tablet orientation offers portrait (0°), landscape right (90°), upside-down portrait (180°), and landscape left (270°). The entire interface, input mapping and dialogs rotate; the document itself is not rewritten. Changes wait for active editing interactions or modal dialogs to finish. In 0.2.8, **Rotate automatically with the tablet** can use a supported sensor and is off by default. The switch is available when the sensor is detected, or remains available to disable a previously saved setting. A status message explains unavailable hardware. Stable upright positions select one of the four angles; flat or ambiguous movement does not immediately rotate the screen. Sampling pauses during PIN lock and sleep. Selecting a manual angle disables automatic rotation. On Mac, resize the window; tablet rotation controls are disabled.

Global reading zoom offers 100%, 125%, 150% and 200%. In an open book, **Reading preferences** supports 100–300%, four margin sizes, the app orientation or a chosen angle, and the swipe action. Pinch zoom is remembered locally after the gesture. **Use general settings**, followed by **Apply**, removes that book's overrides; **Cancel** leaves them intact. These choices are stored separately from notebook content, so synchronization does not overwrite another device's viewing preferences. They do not change the PDF/EPUB, annotations or page numbers. A fixed reading orientation overrides automatic rotation while reading that book. Choose the app orientation in the effective reading preferences to follow the sensor; without a valid sensor angle, the saved manual angle remains the fallback.

**Open pages full screen** controls entry from the library. **Show tools** restores the editor controls on the current page. The status bar is hidden in full-page view. Quick controls remain available when enabled and no editing interaction or modal dialog is active.

On a sheet without a book background, pinch with two fingers to zoom and move both fingers together to pan when zoomed. Tap the zoom percentage to fit the sheet again. Sheet zoom is temporary and separate from saved book preferences.

**Reset display settings** disables automatic rotation and restores manual rotation, interface size, indicators, clock format/zone, profile, handedness, toolbar, quick controls, gestures, global reading defaults, contrast and label weight. It leaves per-book overrides, sleep/charging, PIN, recognition, synchronization, backups, cache limit, Apple destinations and the independent refresh controls unchanged.

## Recognition and table editing

Tap an occupied table cell briefly with the Marker, or any cell with a finger, to open the table editor at that address. Empty cells still accept pen strokes. With the lasso, review the recognized text or cell values before applying them. The keep-ink preference also initializes the handwriting-to-cells review; changing it there affects that operation. Raw formulas remain editable in the table editor, and linked charts recompute from saved cell results. See [Lasso and handwriting](LASSO.md) and [the user guide](USER_GUIDE.md).

## Diagram-recognition suggestions

In **Pen and recognition**, **Recognize diagrams automatically** controls suggestions in diagram notebooks and is on by default. The same preference is available in the diagram workspace toolbar. After a drawing pause, Quaderno can offer a preview without opening an editor or changing the page. Open the suggestion to review shapes, arrows and labels, then explicitly apply it. **Close** dismisses the suggestion; a later stroke can trigger a new one. The lasso action also works on drawings in other sections. Ambiguous strokes and labels you exclude remain ink. Turning suggestions off leaves manual recognition available. See [Diagrams](DIAGRAMS.md).

This preference is local to the installation, separate from the diagram objects and from the display reset. Recognition waits while the page is being edited, locked or sleeping, or a modal operation is active.

## Automatic work, storage and privacy

Automatic sync covers selected notebooks and an already paired peer while both apps are open and unlocked. In **Automatic (Bluetooth and Wi-Fi)**, the apps use Bluetooth to detect pending work. They switch to Wi-Fi if Paper Pro and Mac are reachable on the same subnet and the configured rules allow it. Turn on Bluetooth on both devices before using this mode. **Wi-Fi only** and **Bluetooth only** use the selected connection. Trusted SSIDs constrain automatic Wi-Fi. With a configured list, the system must be able to read the SSID and it must match an entry exactly. The charging-only option applies to both connections. PIN lock, standby, open editors, pending review and active operations pause dispatch. An apply already committing finishes its atomic operation before later work is gated. [Automatic synchronization triggers, recovery and limits](SYNC_PROTOCOL.md#automatic-synchronization).

Scheduled local backups also wait until Quaderno is open and available. A new snapshot must succeed before retention removes older verified snapshots belonging to this library. Altered, foreign or unverified folders are not deleted. Backups contain notebook data and a separate copy of local book-reading preferences; they exclude cloud tokens, PIN and global settings. Copy backups to another device to protect against loss of the tablet. Restoring the portable notebook file does not automatically restore its separate reading-preferences sidecar.

The cache size applies separately to cached page images in memory and derived PDF files on disk. It is not a total process-memory ceiling. Visible pages and active render jobs can use additional memory. Clearing the cache can make the next page load slower; Quaderno regenerates derived data from the original. See [Local backups, storage and reading preferences](LIBRARY_MAINTENANCE.md) for retention, recovery and cache limits.

## Pen, battery, sleep and keyboard

**Pen and battery** reads firmware telemetry. A current valid reading shows a percentage and charging state; unknown, undocked-stale or malformed values are not displayed as 0%. The checked Paper Pro reported its attached Marker at 100%, present and fully charged. This sample does not verify every pen state.

**Quaderno sleep** offers 2, 5, 10, 20, 30 or 60 minutes, default 20. **Stay awake while charging** defers this automatic sleep while charging is reported; **Sleep now** still works. The separate PIN automatic-lock timeout continues to apply. Available reading-light controls adjust the current session.

Choose Italian or English independently from the Italian QWERTY or English (US) QWERTY keyboard layout. A detected physical Bluetooth or USB keyboard hides the on-screen keyboard. See [Connect a Bluetooth keyboard](USER_GUIDE.md#connect-a-bluetooth-keyboard).

## SSH access on Paper Pro

On Paper Pro in Developer Mode, open **Settings → SSH access**. The panel reads the service status when it opens. Use **Enable** or **Disable** to change access and **Refresh status** to check it again.

- **Wi-Fi.** Quaderno uses reMarkable’s official setting, which persists across restarts. Once enabled, use the tablet’s Wi-Fi IP address from a computer on the same network. [reMarkable Developer Mode](https://developer.remarkable.com/documentation/developer-mode#using-developer-mode)
- **USB-C.** The control applies to the two USB SSH listeners verified on firmware 3.29.1.0. Disabling them blocks new connections over the cable until you enable access again in the panel or restart the tablet. Existing sessions can continue.
- **Bluetooth.** The status is **Unavailable** because the checked firmware has no dedicated SSH listener for a Bluetooth PAN.

Change access on Paper Pro. On Mac, use **Settings → USB-C** to check whether SSH responds at `10.11.99.1:22`.

## Accounts and cloud files

The hub offers Google Drive, Dropbox and OneDrive account dialogs with authorization, file browsing, download/import, upload of new copies, cancellation and disconnect. **This requires an official OAuth client registration for the installation.** Missing registration is shown as unavailable; opening a website is not treated as a connected account. The source implementation is not evidence of successful live provider authorization: registration setup, provider approval where required, and real-account verification remain separate work.

Passwords are entered only on the provider's official page. Google uses a browser flow with PKCE and a loopback callback; Dropbox uses its official authorization page and a returned authorization code; Microsoft uses its device code page. On Paper Pro, the Mac helper `scripts/cloud-auth-paper-pro.py` opens the browser and handles the SSH authorization handoff. Google callbacks are forwarded to the tablet; access/refresh tokens stay on the tablet. On Mac, tokens use Keychain; on Paper Pro they use a private file outside the library and its backups. PIN lock cancels active authorization and transfer UI operations.

Supported imports are PDF, EPUB, Markdown, CSV, images and `.quaderno`, subject to transfer and format limits. Cloud transfers are manual, up to 100 MiB per supported file and 64 MiB per notebook; format importers can impose smaller limits. Uploads create new copies and do not overwrite or delete cloud originals. Downloading/importing does not establish automatic two-way cloud synchronization. Disconnect removes local saved access without deleting local or cloud files; provider-side revocation is a separate option, with Microsoft's permissions managed on its account page. See [Cloud account setup](CLOUD_ACCOUNTS.md).

Obsidian Sync retains its separate CLI setup and subscription requirement; Quaderno sends Markdown text, while strokes, tables and charts remain Quaderno objects. Public Markdown import requires a direct HTTPS UTF-8 file URL, up to 256 KiB; an HTML sharing page is not a Markdown file. Obsidian Publish links and a local Mac vault remain separate workflows. See [Connect Obsidian Sync](INSTALLATION.md#connect-obsidian-sync).

Apple workflows still use Quaderno on Mac for Notes, Books, Numbers, Keynote and Journal handoff. Books import accepts local DRM-free PDF/EPUB files. There is no direct Apple Account/iCloud sign-in on Paper Pro. See [Notes, Books and iCloud on Mac](USER_GUIDE.md#notes-books-and-icloud-on-mac) and [Wireless sync](USER_GUIDE.md#wireless-sync).
